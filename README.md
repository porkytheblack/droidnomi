# Droidnomi, where droids run free.
Dear builders,
we set out to build a simulation
one that our droids can participate in
one where stories can be told,
wars can be fought,
loyalty can be bought.
But simulations are hard things,
and they take a lot.
They take perserverance and effort,
they can't be conjured up by whatever magic wands you hold.
We do these things not because they are easy,
but because they are hard,
because we are hungry for discovery,
because our curiosity knows no bounds.
So ye brethren, with mighty compute and token budgets,
lay them down for the experience.
What lays ahead is of a lifetime.

- By Droid Enthusiast: Don
